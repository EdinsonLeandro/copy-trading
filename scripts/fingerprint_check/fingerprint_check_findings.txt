ISSUE FOUND (fixed): UA string vs. Client Hints/Worker mismatch
  - navigator.userAgent reported "Chrome/124.0.0.0" - this was a hardcoded
    DEFAULT_USER_AGENT constant in browser_session.py, pinned to an old
    Chrome version.
  - navigator.userAgentData (Client Hints) AND the Worker-thread context
    both reported the browser's REAL engine version: Chromium
    151.0.7922.34.
  - CreepJS flagged this itself (highlighted the Navigator and Worker
    sections as inconsistent/"lie").
  - Why this matters: a stale/spoofed UA string that disagrees with
    Client Hints is a cheap, high-confidence bot signal for any serious
    fingerprinting/anti-fraud vendor to check (Binance's leaderboard very
    likely sits behind one). This was probably a meaningful contributor
    to the observed throttling/timeouts.
  - FIX APPLIED: removed the hardcoded user_agent from both new_context()
    calls in browser_session.py. Playwright's default UA always matches
    the actual installed Chromium build across main thread, Workers, and
    Client Hints, so there's nothing to keep in sync going forward.
  - VERIFIED (2026-09-23 re-run): navigator.userAgent now reports
    "Chrome/151.0.0.0", matching navigator.userAgentData ("Chromium 151
    (151.0.7922.34)") and the Worker-context userAgent/userAgentData.
    CreepJS's Worker panel is no longer flagged/pink. Mismatch resolved.
